## frame 元素 JSON 结构对齐徕珂印 frame 组件（同日第二次迭代）
- `PsdFrameJson` 重写为参考结构：`{ name, type:'frame', width, height, x, y, zIndex, rotate, isFlipX, isFlipY, isLocked, isNeedEdit, imgList:[], config:{...}, isSelected, id(uuid), isTemplate:false }`
- `config` 含 `contentImageUrl`（填充图=图层像素 dataURL）、`maskImageUrl`（遮罩图）、`viewBoxWidth/Height`、`imgContent*`、`aspectRatio` 等，字段与徕珂印 frame 组件一一对应
- 遮罩图生成 `layerToMaskDataURL()`：图层像素转「RGB 全白 + 保留 alpha」的 PNG——SVG `<mask>` 默认亮度遮罩（值=亮度×alpha），白底+alpha 即等价于图层 alpha 形状，与徕珂印 maskImageUrl 用法一致
- 导出 `buildFrameSvg(frameJson)`：按 config 构建 `<svg><defs><mask id="mask-{id}"><image href=maskImageUrl/></mask></defs><image href=contentImageUrl mask="url(#mask-{id})"/></svg>`（store 渲染用，结构同 frame 组件模板 svg-show）
- 所有 data 元素的 `order` 字段统一改名 `zIndex`；frame 元素 id/config.id 用 `crypto.randomUUID()`
- store `importFromPsd` frame 分支改用 `buildFrameSvg(item)` 生成渲染 SVG，`image` 字段取 `config.contentImageUrl`

## 拖拽素材到 frame 上替换填充图（同日第三次迭代）

- store 新增 action `replaceFrameImage(id, url, natural?)`：仅替换 SVG 的 content image，遮罩 maskImageUrl 不变；传图片原始尺寸时按 **cover 裁切**（取较大缩放比 + 居中偏移，超出部分由 SVG 视口裁掉），无尺寸则拉伸铺满
