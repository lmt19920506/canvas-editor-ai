# 2026-09-08

## canvas-editor-ai：新增 PSD 解析导入功能
- 依赖：新增 `ag-psd@31.0.2`（浏览器端可直接用 DOM canvas，无需 initializeCanvas；`typeof document !== 'undefined'` 时自动生效）。
- 新增 `src/utils/psd.ts`：`parsePsdFile(file)` 解析 PSD：
  - 遍历图层树（分组递归），ag-psd `children` 为自底向上顺序，与编辑器「数组末尾=最上层」一致。
  - 区分文字/图片图层生成两套 JSON：`texts: PsdTextJson[]`（content/fontSize/fontFamily/fontWeight/lineHeight/color，source 保留 PSD 原始字号/字体/leading/box）、`images: PsdImageJson[]`（dataURL src，source 保留 canvas 宽高/box）。
  - 每项带全局 `order` 序号，导入时排序恢复 z-index。
  - 坐标按 `scale = min(DESIGN_W/psd.w, DESIGN_H/psd.h)` 等比缩放 + 居中 offset。
  - 文字样式取自 `layer.text.style`（v31 新 API：font.name/fontSize/fillColor/fauxBold/leading），兼容 styleRuns；颜色支持 RGB/FRGB。
  - 隐藏图层跳过并记录原因；跳过合成图/缩略图/智能对象外链以省内存。
- `src/stores/editor.ts` 新增 action `importFromPsd(result)`：文字/图片按 order 合并排序 push，文字用 measureText 校正包围盒，图片按 MIN_ELEMENT_SIZE 兜底。
- `src/App.vue` header：新增「▣ 解析 PSD」按钮（隐藏 file input，解析中禁用）、「⤓ 下载 JSON」按钮（导入成功后出现）、顶栏状态提示（成功/失败两态）；解析 JSON 同时 console.log 输出。
- typecheck 与 build 均通过。
