# 2026-09-17

## canvas-editor-ai：frame 双击编辑模式（滚轮缩放填充图）
- 需求：双击 frame 元素进入编辑模式，滚轮缩放 mask 内的填充图
- 状态放 store（交互统一在 canvas 上，元素层 pointer-events:none）：`editingFrameId` + `startEditFrame/stopEditFrame`
- `FrameElement` 新增 `imgScale`（缩放倍数，1 = cover 基准）
- store 新增 `scaleFrameImage(id, factor)`：以内容中心为锚点缩放 imgContent*；钳制缩放比（下限 = 仍盖满 viewBox，上限 10 倍）并钳制平移（不露底）；`replaceFrameImage` 换图后重置 imgScale = 1；clearAll 重置 editingFrameId
- `useCanvasEditor`：新增 `dblclick`（命中 frame → 进入/再双击退出；其他 → 退出）与 `wheel`（编辑模式下 preventDefault，上滚 ×1.1 / 下滚 ÷1.1，`passive:false`）；pointerdown 点击其他元素/空白、Esc 均退出编辑
- `ElementFrameView` 新增 `editing` prop：虚线 outline + 顶部「滚轮缩放图片 · 双击 / Esc 退出」提示
- typecheck / build 通过

## frame 编辑模式：拖动平移填充图（同日补充）
- store 新增 `moveFrameImage(id, left, top)`：钳制平移（`[viewBox - 内容尺寸, 0]`），保证不露底
- `useCanvasEditor` 新增 `PanFrameDrag` 拖拽态：编辑模式 pointerdown 命中编辑中的 frame → 拖动 = 平移 `imgContentLeft/Top`（不是移动元素）；8 控制点缩放仍可用；退出编辑后拖动恢复正常移动元素
- 编辑提示文案更新为「滚轮缩放 · 拖动调整位置 · 双击 / Esc 退出」
- typecheck / build 通过
